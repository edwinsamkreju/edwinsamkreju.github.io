DotCode

Reversible Dot-Based Programming Suite

A family of dot-based esoteric programming languages with reversible, Python-interoperable tooling. Features Dot (unary dot-length encoding, *.dcode) and NumDot (numeric dot-terminated, *.nd).

Quick Installation

$ pip install dotcode

Dot & NumDot CLI

$ dot compile hello.py
$ numdot run hello.nd

Lossless & Reversible

Provides 100% losslessly reversible code compilation and execution with built-in runtime decoders.
