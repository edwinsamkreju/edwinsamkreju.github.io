Privacy Policy

Last updated: October 2026

TL;DR: Opinova is built with a local-first philosophy. I created Opinova as a personal project to give users full control over their data. Your datasets and local database remain stored strictly on your device.

1. Local Data Storage & Ownership

Opinova operates on a local-first architecture. All opinions, feedback entries, suggestions, categories, and analytical outputs are stored in an offline database residing directly on your computer.

  • No feedback data is ever collected, tracked, or sent to any central server hosted by me.
  • You maintain total ownership and control over your locally stored databases and exported report files (CSV/PDF).

2. Gemini API & Third-Party Processing

To deliver AI-powered decision intelligence, Opinova interacts with Google's Gemini API using the API key you provide during setup:

  • Your API Key: Your Google Gemini API key is stored locally in your app settings on your machine and is only used to authorize analysis requests.
  • Data Transmission: Only the text prompts and feedback data necessary for generating summaries or priorities are transmitted to Google's API endpoints via secure HTTPS.
  • Google's Privacy: Data processed via the Gemini API is governed by Google's Privacy Policy and AI Studio Terms of Service.

3. Analytics and Telemetry

Opinova contains zero telemetry, tracking scripts, or analytics engines. There is no automated usage data collection or error reporting sent back to the developer.

4. Open Source Transparency

Opinova is open-source software licensed under Apache 2.0. You can inspect, audit, or build the entire codebase from source directly on GitHub to verify all privacy mechanisms.

5. Contact

If you have any questions or feedback regarding Opinova's privacy approach, feel free to open an issue or reach out via the official GitHub repository.
